# 阶段2：深度图选点与 SDK 相机坐标

日期：2026-11-01。用户明确将 RGB 排查延后；本阶段只使用深度流。

## 验收状态

已实机完成：实际参数读取、单深度实时显示、鼠标选点、原始深度读取、SDK XYZ 转换、坐标约定统一、无效点拒绝及原始帧留存。

仍未通过：工厂标定主点和 SDK 投影主点差异的物理验证，以及深度输出畸变/去畸变状态确认。
因此本阶段的基本交互与数据链路已通过，但完整几何正确性尚未验收，不能把结果当成已标定的机器人操作坐标。

## 本机实际参数

640×480，标称30 FPS，DEPTH_1_MM，uint16，每 raw unit 为1 mm。
点选模式在启动流之前关闭镜像并核对返回值；无裁剪、无 RGB 注册，不套用彩色像素坐标。
像素原点为深度图左上，u向右、v向下。

## 坐标模型与畸变限制

通过 SDK 的已知输入投影试验，当前输出模型等效 fx/fy 约580.2138、cx/cy约320/240。
该中心来自对当前 SDK 转换的数值核对，不是将半幅尺寸猜作工厂主点。
试验输入Z=1000 mm是几何函数测试值，不是现场测量值。

SDK 原生 convertDepthToWorld 返回图像右为+X、图像上为+Y、前方为+Z。
应用将 Y 符号反转，输出坐标系命名为 `camera_depth_optical_sdk`：

- 原点：SDK 深度相机光学模型原点，尚非机械臂基座。
- X向图像右、Y向图像下、Z沿光轴向前。
- JSON position_m 使用米；界面 display_xyz_mm 使用毫米，两者字段明确分开。
- Y符号变换是坐标约定转换，不是手眼外参旋转标定。

本机畸变状态查询返回 status=4，不支持；返回的占位数值0不能解释成“畸变已关闭”。
工厂畸变系数非零，SDK 投影中心也与工厂值有差别。
当前采用用户要求优先的官方 SDK 转换，保留其模型定义，不额外对深度像素套一次手写畸变矫正，以免重复矫正。
这项选择并未解决输出是否已去畸变的未知状态，结果明确携带 geometry_verified=false 与 physical_accuracy_verified=false。

已核对 [OpenNI 官方 API 说明](https://github.com/orbbec/OpenNI_SDK/blob/main/Doc/English/0400_API.md)、包内 OpenNI.h、GeneratePointCloud、SimpleViewer 源码，以及 [Orbbec ROS 参数实现](https://github.com/orbbec/ros_astra_camera/blob/main/src/ob_camera_info.cpp)。
不同实现采用的投影约定并不完全相同，不能据此直接宣称几何误差已消除；没有安装 ROS 或额外 SDK。

后续需通过厂商明确的输出几何定义或独立几何标定/参考测量，确认工厂参数到实际深度像素的映射。
SDK 坐标往返像素一致仅证明函数链路一致，不证明物理准确度。

## 有效性与边缘处理

默认应用接受范围为600–4000 mm，这是学习场景的门限，不是已验证精度范围。
0、SDK编码范围外、应用门限外、图像最外圈像素均拒绝。
3×3邻域至少7个有效样本；有效深度极差超过 max(10 mm, 中心深度的2%) 时拒绝，防止混合前景背景。
这两项是保守启发式质量门限，不是厂商准确度保证。
显示帧距点击超过0.5秒时拒绝，避免把陈旧帧当当前测量。

位置使用被点击像素本身的深度，不用邻域中位数替换、不跨空洞寻找替代点。
邻域只用于质量检查。若以后加入局部中位数，必须说明多数样本属于同一表面的前提。
已通过8项离线算法检查（正常、越界、边框、无深度、SDK范围、应用范围、邻域稀疏、深度跳变）；离线检查与实机点击记录分开。

valid=true 仅表示深度质量门限与 SDK 转换成功，不代表完整几何标定合格。
结果同时包括设备时间戳、主机收帧/点击时间、帧序号、帧年龄、坐标系、单位、质量及几何验证状态。
所有点都是可见表面采样点，不是物体中心、六维姿态或抓取位姿。

## 运行

```bash
bash scripts/build_ir_preview.sh
.venv/bin/python camera/astra_pro_plus/depth_point.py --output data/point-new-session
```

使用新目录防止覆盖。左键点击有效色块内部，黑区将返回NO_DEPTH；Q/Esc退出。
为保证点击像素对应原图，窗口使用固定图像尺寸，底部说明区不接受点选。
界面显示“最后一次点击”，不是跟踪；点击时保存的原始帧与时间戳对应同一次测量。

停止其他相机查看器后再启动。本程序不调用 RGB、不使用机械臂接口。
